# victoriawordsworth.com

Source code for my personal website at [victoriawordsworth.com](https://victoriawordsworth.com).

## Tech stack

- Plain HTML, CSS, and JavaScript — no build step
- [Web3Forms](https://web3forms.com) for contact form submissions
- [Behold](https://behold.so) widget for Instagram feed
- Hosted on GitHub Pages

## Running locally

Open `index.html` in a browser — no server or dependencies required.
